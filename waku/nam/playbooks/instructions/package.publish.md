# package.publish: Push the documents to Aarohan

FRS: F40, F50
Stage: S8, S9, S10
Gate: none

## Purpose

List the files to upload to the Aarohan procurement file, in the FRS order, and record the upload made by hand.

## Steps

1. List the frozen package's files at their latest version: SCC, PQC, BOQ, QCBS file, specification or scope of work, then the rest.
2. Say that nothing is sent: there is no Aarohan connector.
3. Record the Aarohan reference once uploaded (answer `aarohan_ref`).

## Rules

- Only a frozen package is uploaded.

## Tools

None.

## Outputs

- The upload list and the Aarohan reference.
