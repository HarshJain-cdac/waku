# case.status: Show the case status

FRS: F5
Stage: any
Gate: -

## Purpose

Tell any role that may see the case where it stands.

## Steps

1. Read the Need Record.
2. Report its stage, version, selected precedent and any open question.

## Rules

- Read only: this flow writes nothing.

## Tools

None.

## Outputs

- The case's stage, version, selection and open question.
